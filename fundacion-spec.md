\# 🌱 Fundación Un Plan Con Café — Product Specification



\## 1. 🎯 Purpose



Build a \*\*mobile-first web platform\*\* that maximizes \*\*donations\*\* by combining:



\* Emotional storytelling

\* Transparent impact

\* Simple and fast donation flows



The platform must prioritize \*\*conversion (donations)\*\* over exploration.



\---



\## 2. 👤 Target Users



\* Donors (primary)

\* Volunteers

\* General audience interested in social impact



\---



\## 3. 🧭 UX Strategy (Critical)



\### Primary Action



👉 Donate



\### User Journey (Mobile)



1\. User lands on homepage

2\. Sees emotional message + real context

3\. Gains trust via impact metrics

4\. Clicks \*\*"Donar ahora"\*\*

5\. Completes donation in minimal steps



\---



\## 4. 🧱 Homepage Structure



\### 1. Hero Section



\* Emotional headline (non-generic)

\* Short supporting text

\* CTA: \*\*Donar ahora\*\*

\* Visual (image or background)



\### 2. Impact Section



\* Key metrics:



&#x20; \* Families supported

&#x20; \* Active projects

&#x20; \* Total donors



\### 3. Projects Preview



\* List of active projects

\* Each with:



&#x20; \* Title

&#x20; \* Short description

&#x20; \* Progress indicator



\### 4. Story / Media Section



\* Real stories or podcast content

\* Emotional reinforcement



\### 5. Donation Section



\* Reinforced CTA

\* Short explanation of impact



\### 6. Products Section



\* Purpose-driven products

\* Each product tells a story



\### 7. Events Section



\* Upcoming events

\* Basic info (date, purpose)



\---



\## 5. 💳 Donation Flow (IMPORTANT)



Define behavior:



\* Clicking "Donar ahora" should:



&#x20; \* \[ ] Open modal

&#x20; \* \[ ] Navigate to donation page

&#x20; \* \[ ] Redirect to external provider



⚠️ This must be decided before backend implementation.



\---

\## 9. 🤖 Instructions for OpenClaw



When generating code:



\* Prioritize \*\*mobile-first design\*\*

\* Avoid generic templates

\* Focus on \*\*donation conversion\*\*

\* Use clean semantic HTML

\* Keep CSS simple and scalable



When generating tasks:



\* Break into small, actionable units

\* Separate frontend and backend clearly

👉 Ask questions instead of assuming
